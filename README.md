# Trabix Granizados Website

Static marketing website for Trabix Granizados — plain HTML/CSS/JS, no framework. Segments:
`retail/`, `volumen/`, `alianzas/`.

> **Lee `ROADMAP.md` al iniciar sesión** — dice qué está pendiente acá y por qué este sitio no es el
> canal de venta (los anuncios van directo a WhatsApp, no pasan por la web).

Identidad visual (paleta, tipografías): `../brand_identity.md`.

## Local preview

Sirve la carpeta con cualquier servidor estático, p. ej. `npx serve .` o
`python3 -m http.server`. Producción: <https://www.trabixgranizados.xyz>

## Deploy

The project is configured for Vercel with `vercel.json`.
